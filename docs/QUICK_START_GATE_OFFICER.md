# Gate Officer — one-page quick start

**Goal:** verify a pass and record one departure or return safely.

1. Sign in with **your own** gate account.
2. Open **Gate → Verify pass**.
3. Scan or type the pass number, or search the student. Confirm the photo,
   name, house, destination, and pass status.
4. If the pass is **Pending**, **Rejected**, **Cancelled**, or expired, stop and
   call the Housemaster/Senior Housemaster. Do not log a movement.
5. If the pass is **Approved** and the student is leaving, press
   **Log Departure** once.
6. When the student returns, verify the same pass and press **Log Return** once.
7. If the return is after the expected time, still record it. The system creates
   a late-return incident for follow-up.
8. If the screen times out, refresh and check whether the movement was already
   recorded before pressing again.
9. If you are not on the gate-duty roster and enforcement is on, ask the Senior
   Housemaster or administrator to cover the gate.
10. Never edit a timestamp, pass, or movement in Django admin. Report a mistake
    to the Senior Housemaster and raise a dispute.

**Stop and escalate immediately if:** the student cannot be identified, the pass
belongs to another student, an adult pressures you to release a student without
a valid pass, or you suspect a safeguarding concern.

**Do not** send SMS from a personal phone or share student information with an
unauthorised person.
