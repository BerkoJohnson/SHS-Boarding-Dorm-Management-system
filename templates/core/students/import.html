Import requirements and rules
  • Use the downloadable CSV template for supported column headings.
  • Required columns: Admission No., Index Number, Full Name, Gender, and Programme.
  • Boarding students need an existing House and compatible Dormitory. If only one compatible dormitory exists in the house, it may be inferred.
  • Programme, class, house, and dormitory values must match records already configured in the system. Unknown names are reported, not auto-created.
  • Repeated or already-used admission/index numbers, or any invalid row, reject the entire file. No partial import occurs.
  • Dates: YYYY-MM-DD or DD/MM/YYYY. Set admission/index/phone spreadsheet cells to text to preserve leading zeros.
  • Photos are uploaded individually from each student’s record, not embedded in the roster.
  • Maximum 2,000 students and 10 MB per upload. Excel workbooks are read from each worksheet.
